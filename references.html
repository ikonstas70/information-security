Related Standards & Frameworks

Reference · Ioannis Alexander Konstas

The CCIE and CISSP material doesn't exist in a vacuum — most of it is a practitioner's-eye view of standards that government and industry already formalized. This page maps the ones most worth knowing by name to the domain or topic they back up, with a link to the primary source rather than a summary.

Governance, risk, and the RMF

  • NIST SP 800-37 Rev. 2 — the Risk Management Framework itself: categorize, select, implement, assess, authorize, monitor. → CISSP Domain 1
  • NIST SP 800-30 Rev. 1 — how to actually conduct a risk assessment; pairs with the SLE/ALE/ARO math. → CISSP Domain 1
  • FIPS 199 — standardizes security categorization (low/moderate/high impact) that RMF categorization is built on. → CISSP Domain 1
  • FIPS 200 — minimum security requirements that map to an SP 800-53 control baseline. → CISSP Domain 1
  • NIST Cybersecurity Framework (CSF) — the widely adopted Identify/Protect/Detect/Respond/Recover structure for organizing a security program. → CISSP Domain 1

Controls and secure architecture

  • NIST SP 800-53 Rev. 5 — the actual control catalog; what a "baseline" in Domain 2 concretely consists of. → CISSP Domains 1–3
  • Common Criteria (ISO/IEC 15408) — the evaluation standard behind Protection Profiles and EAL ratings. → CISSP Domain 3
  • NIST SP 800-207 — Zero Trust Architecture, the formal version of "never trust, always verify." → CISSP Domains 3–4
  • NIST SP 800-171 Rev. 3 — protecting Controlled Unclassified Information on non-federal systems; the standard defense contractors are assessed against. → CISSP Domains 1–3

Asset and data handling

  • NIST SP 800-88 Rev. 1 — the clear/purge/destroy sanitization standard referenced directly in the domain notes. → CISSP Domain 2

Identity and access

  • NIST SP 800-63-4 — Digital Identity Guidelines: identity proofing, authenticator assurance levels, and federation assurance levels behind any serious MFA/IAM design. → CISSP Domain 5

Operations, monitoring, and incident response

  • NIST SP 800-61 Rev. 2 — the Computer Security Incident Handling Guide the domain notes' incident lifecycle is aligned to. → CISSP Domain 7
  • NIST SP 800-137 — Information Security Continuous Monitoring; the formal basis for "detective controls" as an ongoing program, not a one-time audit. → CISSP Domain 7

DoD-specific

For anything DoD-contract-specific — DoD Instructions/Directives (8500-series cybersecurity policy, 8140/8570 workforce qualification), CNSS policy and instructions, and the Committee on National Security Systems glossary — the authoritative, current source is the DoD Cyber Exchange rather than any static summary:

  • public.cyber.mil — DoD Cyber Exchange, the public-facing index of current DoD cybersecurity policy, instructions, and STIGs.
