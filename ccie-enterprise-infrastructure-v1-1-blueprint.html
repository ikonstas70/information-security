CCIE Exam Blueprint

CCIE Enterprise Infrastructure v1.1 — Exam Topics

Reference · Ioannis Alexander Konstas

The CCIE Enterprise Infrastructure (v1.1) Lab Exam is an eight-hour, hands-on exam that requires a candidate to plan, design, operate, and optimize dual-stack solutions (IPv4 and IPv6) for complex enterprise networks. Candidates are expected to program and automate the network within the exam, per the topics below.

The following topics are general guidelines for the content likely to be included on the exam. Knowledge, skills, and abilities on these topics are tested throughout the entire network lifecycle, unless explicitly specified otherwise.

1.0 Network Infrastructure 30%

1.1 Switched campus

  • 1.1.aSwitch administration
    • Managing MAC address table
    • Errdisable recovery
    • L2 MTU
  • 1.1.bLayer 2 protocols
    • CDP, LLDP
    • UDLD
  • 1.1.cVLAN technologies
    • Access ports
    • Trunk ports (802.1Q)
    • Native VLAN
    • Manual VLAN pruning
    • Normal range and extended range VLANs
    • Voice VLAN
  • 1.1.dEtherChannel
    • LACP, static
    • Layer 2, Layer 3
    • Load balancing
    • EtherChannel misconfiguration guard
    • Identify multichassis EtherChannel use cases
  • 1.1.eSpanning Tree Protocol
    • PVST+, Rapid PVST+, MST
    • Switch priority, port priority, tuning port/path cost, STP timers
    • PortFast, BPDU guard, BPDU filter
    • Loop guard, root guard
